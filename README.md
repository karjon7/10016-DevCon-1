# DevCon #1 – Game Design Document

## 1. Mechanic Definition
A hold-and-drag interaction system thats more than just "press E to pick up"
Players aim at an object and hold or drag with the mouse. Light objects get carried,
heavy objects get dragged slowly, and drawers and doors open by dragging. 
Interactions between object have to be in world (key has to be dragged into door)

## 2. Objective Statement
**Question:** Does hold-and-drag interaction feel more tactile, engaging and rewarding than press-E pickup?
**Why:** Most games make interaction a button press. I want to see if adding physical
effort makes objects feel more real.

## 3. Design Rationale
**Experience:** Deliberate, weighty, and satisfying. Interactions should feel apart of the games deliberate "friction"
**Innovation:** Objects have weight and resistance, and different objects need different actions.

## 4. Interaction Flow
1. **Idle:** the player walks around.
2. **Focused:** the player looks at an object and it highlights.
3. **Holding:** the player presses and holds the mouse to grab it.
4. **Dragging:** the player moves the mouse and the object follows, with weight and resistance.
5. **Release:** the player lets go and goes back to Idle.
(Maybe Jammed items that require shaking the mouse to set free)
